## Пути 
- Абсолютный путь — путь начинающийся с корня файловой системы
- Относительный путь — путь относительно текущего каталога
- `~` — домашний каталог
- `.` — текущий каталог
- `..` — родительский каталог
- Пример: я в /home/user/Documents, путь к /home/user/test/a.txt — ../test/a.txt 

## Команды для файлов и папок
- `pwd` — выводит текущий каталог
- `ls -la` — выводит подробную информацию о файлах/каталогах, находящихся в текущем каталоге, включая скрытые
- `cd` — меняет текущий каталог
- `mkdir -p` — помогает создать новую папку в новой папке
- `cp -r` — рекурсивное копирование каталога в другой каталог
- `mv` — перемещение файла/каталога в новое место, чатсный случай - переименовывание
- `rm -r` — рекурсивное удаление каталога
- `ln -s ЦЕЛЬ ИМЯ` — создание символческой ссылки. Пример: ln -s /home/euset/doc/a.txt link_to_a.txt

## Чтение файлов
- `cat` — выводит содержимое файла в терминал 
- `less` — выводит содержимое файла в интерактивном окне (поиск: /... , выход: q)
- `file` — определить тип по содержимому файла ; `file -i` — определить MIME-формат файла + тип кодировки

## Поиск
Синтаксис: `find ПУТЬ УСЛОВИЯ` — путь всегда первым!
- `-name "*.txt"` — по имени, `*` — любые символы
- `-type f` / `-type d` — только файлы / только папки
- `-size 33c` — размер ровно 33 байта (`c` = байты)
- `-user имя`, `-group имя` — владелец, группа
- `! -executable` — не исполняемый (`!` = «не»)
- `2>/dev/null` — выбросить ошибки, оставить результат

## ls -l по столбцам
Пример строки: `-rwxr-x--- 1 ivan staff 2048 Oct 20 14:00 run.sh`
1. первый символ - файл или каталог, остальные 9 символов - права владельца, группы и остальных
2. количество ссылок
3. владалец
4. группа
5. размер в байтах
6. дата последнего изменения
7. название

## Python (новая для меня информация)
- f-строки: `f"{'текст':-^20}"` — `<` влево, `>` вправо, `^` по центру, перед ними символ заполнения; текст внутри {} в кавычках
- разделение между элементами вывода (print) можно установить с помощью sep=''. Пример: print('a', 'b', 'c', sep='!'). Выод: a!b!c
- конечный символ после вывода можно установить с помощью end=''. Пример: print('a', end='!\n'). Вывод: a!
